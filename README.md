## 📋 翻译规范

### 命名约定

- 章节文件：`chapter-01.md`（两位数字，前导零）
- 图表文件：`figure-01-02.png`（章节-序号）
- 代码块：保留原文代码，添加中文注释

### 翻译原则

1. **准确性优先**：确保术语翻译准确
2. **可读性**：语言通顺，符合中文习惯
3. **专业性**：金融术语标注英文原文
4. **格式一致**：统一 Markdown 格式
